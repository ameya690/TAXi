## 🏗️ **Architecture**

### Frontend:
```
React + Vite
├── Authentication Context
├── Components
│   ├── LoginPage (SSO)
│   ├── Chat (with history)
│   ├── EligibilityCalculator (advanced)
│   ├── ChatHistory (export)
│   ├── SavedCalculations (persist)
│   └── AdminPanel (monitoring)
├── Localization (EN/ES)
└── Modern Styling (CSS-in-JS)
```

### Backend:
```
Flask + Python
├── Routes
│   ├── /health
│   ├── /api/ask
│   ├── /api/eligibility/schema
│   └── /api/eligibility/assess
├── Services
│   ├── LLM (FLAN-T5)
│   ├── RAG (FAISS + Embeddings)
│   ├── Safety Guardrails
│   └── Advanced Eligibility Rules
└── Knowledge Base (21 docs)
```

### Tech Stack:
- **Frontend:** React 18, Vite
- **Backend:** Flask, Python 3.11
- **AI:** Hugging Face Transformers (FLAN-T5-base)
- **Embeddings:** sentence-transformers
- **Vector Search:** FAISS
- **Storage:** LocalStorage, IndexedDB-ready
- **Auth:** OAuth 2.0 pattern
- **Styling:** CSS-in-JS (inline styles)
