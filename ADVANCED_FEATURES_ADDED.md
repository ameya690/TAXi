## 📖 **How to Use New Features**

### 1. Chat History
1. Click "💬 Chat" tab
2. See "📋 History" button
3. View all past conversations
4. Click "📥 Export" for PDF/JSON

### 2. Document Upload
1. Go to "✅ Eligibility" tab
2. Click "📁 Upload Documents"
3. Drag & drop W-2, 1099 files
4. Auto-populate fields

### 3. Save Calculations
1. Complete eligibility form
2. Click "💾 Save Result"
3. Name your scenario
4. Access from "📊 Saved" menu

### 4. Year Comparison
1. Admin tab → "📈 Compare Years"
2. Enter income for multiple years
3. See credit amounts side-by-side
4. Visual charts

### 5. Generate Report
1. After eligibility check
2. Click "📄 Generate Report"
3. Professional PDF created
4. Print or download
