# Tax Notice Explainer Feature

## Overview

The **"Explain My Tax Notice"** AI Helper is a powerful feature that allows users to upload IRS or state tax notices (PDF or image format) and receive:

- **Automated text extraction** using OCR technology
- **Key details extraction** (notice number, tax year, deadline, amount, etc.)
- **Plain-language summary** generated by AI
- **Actionable next steps** checklist
- **Referenced sections** highlighting which parts of the notice were analyzed

## Features

### 📤 File Upload
- **Supported formats**: PDF, PNG, JPG, JPEG, TIFF, BMP, GIF
- **Maximum file size**: 10MB
- **Drag-and-drop** interface for easy uploading
- **File validation** with clear error messages

### 🔍 Intelligent Extraction
- **Direct PDF text extraction** for searchable PDFs
- **OCR processing** for scanned PDFs and images using Tesseract
- **Pattern matching** to identify key information:
  - Notice number (CP-XXX, LTR-XXXX)
  - Tax year
  - Issue date and response deadline
  - Amounts owed
  - Notice type (Audit, Balance Due, Refund, etc.)
  - Taxpayer ID (last 4 digits only for privacy)

### 🤖 AI-Powered Analysis
- **Plain-language summary** using the local LLM (FLAN-T5)
- **Context-aware explanations** based on extracted content
- **Bilingual support** (English and Spanish)
- **Safety disclaimers** included in all responses

### ✅ Next Steps Generation
- **Contextual action items** based on notice type
- **Deadline reminders**
- **Payment guidance** when amounts are detected
- **Professional consultation recommendations** for audits
- **Documentation requirements** listed when applicable

### 🔖 Referenced Sections
- **Automatic highlighting** of relevant notice sections
- **Relevance scoring** (high/medium)
- **Text excerpts** from the original notice
- **Section numbering** for easy reference

## Technical Architecture

### Backend Components

#### 1. Service Layer (`services/tax_notice_analyzer.py`)
```python
class TaxNoticeAnalyzer:
    - analyze_notice()      # Main entry point
    - _extract_text()       # PDF/image text extraction
    - _extract_key_details() # Pattern matching for key info
    - _generate_summary()   # LLM-based summarization
    - _generate_next_steps() # Action items generation
    - _find_referenced_sections() # Section highlighting
```

**Key Technologies**:
- `PyPDF2`: Direct PDF text extraction
- `pdf2image`: Convert PDF pages to images
- `pytesseract`: OCR for scanned documents
- `Pillow`: Image processing
- `transformers`: LLM integration (FLAN-T5)

#### 2. API Routes (`routes/tax_notice.py`)
```
POST /api/tax-notice/analyze
- Accepts multipart/form-data with file and lang parameters
- Returns JSON with extracted details, summary, and next steps

GET /api/tax-notice/health
- Health check endpoint
- Returns service status and configuration
```

**Request Format**:
```bash
curl -X POST http://localhost:5000/api/tax-notice/analyze \
  -F "file=@notice.pdf" \
  -F "lang=en"
```

**Response Format**:

## Usage Guide

### For End Users

1. **Navigate to Tax Notice Tab**
   - Click on "📄 Tax Notice" in the navigation bar

2. **Upload Your Notice**
   - Drag and drop your PDF or image file, OR
   - Click the upload zone to browse files
   - Supported formats: PDF, PNG, JPG, TIFF (max 10MB)

3. **Analyze**
   - Click "🔍 Analyze Notice" button
   - Wait for processing (typically 10-30 seconds)

4. **Review Results**
   - **Key Details**: Check extracted information for accuracy
   - **Summary**: Read the plain-language explanation
   - **Next Steps**: Follow the actionable checklist
   - **Referenced Sections**: Review highlighted notice sections

5. **Upload Another**
   - Click "📤 Upload Another Notice" to analyze a different document

### Language Support

Switch between English and Spanish using the language selector in the header. The analysis will be performed in your selected language.

## Best Practices

### For Optimal Results

1. **File Quality**
   - Use high-resolution scans (300 DPI recommended)
   - Ensure text is clear and legible
   - Avoid skewed or rotated images

2. **File Format**
   - Searchable PDFs work best (fastest processing)
   - For scanned documents, use PDF or high-quality images
   - TIFF format recommended for scanned documents

3. **Privacy**
   - Only the last 4 digits of SSN/TIN are displayed
   - Files are not stored on the server
   - Processing happens in real-time and data is discarded

### Troubleshooting

**"Could not extract sufficient text"**
- Image quality may be too low
- Try rescanning at higher resolution
- Ensure the document is not password-protected

**"File too large"**
- Compress the PDF or reduce image resolution
- Maximum file size is 10MB

**"Invalid file type"**
- Only PDF and image files are supported
- Check file extension matches actual format

**OCR not working**
- Verify Tesseract is installed: `tesseract --version`
- Check Tesseract is in system PATH
- Reinstall pytesseract: `pip install --upgrade pytesseract`

## Security Considerations

### Data Privacy
- **No persistent storage**: Files are processed in memory only
- **No logging of sensitive data**: Only metadata is logged
- **SSN/TIN masking**: Only last 4 digits displayed
- **HTTPS recommended**: Use SSL in production

### Rate Limiting
- API endpoints are rate-limited (60 requests/minute)
- Prevents abuse and ensures fair usage

### File Validation
- File type checking (whitelist approach)
- File size limits (10MB max)
- Content validation before processing

## API Documentation

### Endpoint: POST /api/tax-notice/analyze

**Request**:
- Method: `POST`
- Content-Type: `multipart/form-data`
- Parameters:
  - `file` (required): PDF or image file
  - `lang` (optional): Language code ("en" or "es", default: "en")

**Response**:
```json
{
  "success": boolean,
  "file_type": string,
  "extracted_text": string,
  "key_details": {
    "notice_number": string | null,
    "tax_year": string | null,
    "issue_date": string | null,
    "response_deadline": string | null,
    "amount_owed": string | null,
    "notice_type": string | null,
    "taxpayer_id": string | null
  },
  "summary": string,
  "next_steps": string[],
  "referenced_sections": [
    {
      "section": number,
      "text": string,
      "relevance": "high" | "medium"
    }
  ],
  "processed_at": string (ISO 8601)
}
```

**Error Response**:
```json
{
  "success": false,
  "error": string
}
```

**Status Codes**:
- `200`: Success
- `400`: Bad request (invalid file, missing parameters)
- `500`: Server error

### Endpoint: GET /api/tax-notice/health

**Response**:
```json
{
  "status": "healthy",
  "service": "tax_notice_analyzer",
  "allowed_extensions": ["pdf", "png", "jpg", "jpeg", "tiff", "bmp", "gif"],
  "max_file_size_mb": 10
}
```

## Performance Considerations

### Processing Time
- **Searchable PDF**: 5-10 seconds
- **Scanned PDF (OCR)**: 15-30 seconds
- **Image (OCR)**: 10-20 seconds

### Optimization Tips
1. **Use searchable PDFs** when possible (fastest)
2. **Limit file size** to reduce upload time
3. **Consider async processing** for production (queue-based)
4. **Cache LLM model** (already implemented)

### Resource Usage
- **Memory**: ~500MB-1GB per request (LLM + OCR)
- **CPU**: High during OCR and LLM inference
- **Disk**: No persistent storage required
